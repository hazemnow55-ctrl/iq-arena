# IQ Arena — اختبار الذكاء

لعبة ويب عربية تفاعلية لاختبار الذكاء عبر جلسات من 10 أو 12 أو 15 سؤالًا، يتم اختيارها عشوائيًا من بنك يضم **108 أسئلة أصلية** في التسلسلات العددية، المنطق، الأنماط البصرية، مصفوفات ريفن، اكتشاف المختلف، الدوران الذهني، الحساب المنطقي، العلاقات، وسرعة التفكير.

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

لفحص الأنواع وبناء نسخة الإنتاج:

```bash
pnpm check
pnpm build
```

توجد اللعبة في `client/src/pages/Home.tsx`، بينما يوجد نظام التصميم المتجاوب في `client/src/index.css`. التطبيق يعمل بالكامل على المتصفح ولا يحتاج إلى قاعدة بيانات أو مفاتيح API.

## النشر على GitHub Pages

المشروع مجهز بملف GitHub Actions في `.github/workflows/pages.yml`. بعد إنشاء مستودع GitHub ورفع المشروع إلى الفرع `main`، فعّل **Settings → Pages → Source: GitHub Actions** مرة واحدة. كل push لاحق سيشغل فحص TypeScript، يبني النسخة الساكنة، ثم ينشر محتوى `dist/public` تلقائيًا.

استخدمت إعداد `base: "./"` في Vite حتى تعمل الأصول على المسار الفرعي المعتاد لمستودعات GitHub Pages، مثل `https://username.github.io/iq-arena/`.

## معاينة الحالات

- `/?demo` يفتح الاختبار مباشرة بوضع معاينة ثابت.
- `/?result` يعرض تقرير نتيجة تجريبيًا للتحقق البصري.

## ملاحظات المنتج

يمكن للمستخدم إدخال الاسم والعمر، اختيار عدد الأسئلة والوقت ومستوى التحدي، وتفعيل أو تعطيل الصوت والحركة وحفظ التفضيلات. النتيجة المعروضة هي مؤشر ترفيهي تقريبي لأداء هذا التحدي وليست تشخيصًا نفسيًا أو اختبارًا سريريًا معتمدًا. جميع الإجابات والنتيجة تبقى محلية داخل المتصفح، مع دعم النقر واللمس واختصارات لوحة المفاتيح `1` إلى `4`.
